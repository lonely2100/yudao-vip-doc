          FMS 演示

          # 1. 演示地址

          FMS（Financial Management System，财务管理系统）用于维护企业从建账、凭证到账簿、报表、结账的完整财务链路，以账套为核算主体，串联设置管理、凭证管理、账簿管理、报表管理、结账管理五大业务域。

          # 1.1 FMS 管理后台

          • 演示地址：http://dashboard-vue3.yudao.iocoder.cn/ (opens new window)
          • 菜单："财务管理"下的「首页」「凭证管理」「账簿管理」「报表管理」「结账管理」「设置管理」
          • 仓库：https://github.com/yudaocode/yudao-ui-admin-vue3 (opens new window) 的 fms 目录，基于 Vue3 + Element Plus 实现

          同一个后台账号可以加入多个账套，通过页面顶部的账套切换器选择当前账套；凭证、账簿、报表和结账等数据，都只在当前账套下查询和维护。

          # 1.2 FMS 后端

          支持 Spring Boot 单体、Spring Cloud 微服务架构

          • 单体仓库： https://github.com/YunaiV/ruoyi-vue-pro (opens new window) 的 yudao-module-fms 模块
          • 微服务仓库： https://github.com/YunaiV/yudao-cloud (opens new window) 的 yudao-module-fms 服务

          # 1.3 FMS 移动端

          FMS 提供 uni-app 移动端，凭证、账簿、报表、结账和设置都可以在手机上处理，详见 《移动端 FMS》。

          • 仓库：https://github.com/yudaocode/yudao-ui-admin-uniapp (opens new window) 的 pages-fms 目录

          # 2. FMS 启动

          参见 《FMS 手册 —— 功能开启》 文档，一般 3 分钟就可以启动完成。

          # 3. FMS 交流

          专属交流社区，欢迎扫码加入。

          # 4. 功能描述

          主要分为 5 个业务域：设置管理、凭证管理、账簿管理、报表管理、结账管理，另外提供财务首页汇总当前账套的核心指标。

          业务以账套为中心：账套完成初始化后，依次维护币别、辅助核算、科目和初始余额，再录入并审核凭证；账簿实时读取初始余额和凭证分录，报表按期间保存公式快照及人工调整数据并实时计算金额，最后完成损益结转和期末结账。

          # 5. 表结构

          FMS 共 30 张表，表名统一以 fms_ 为前缀。

          模块 子前缀 表数量 核心职责
          设置管理 fms_account_*、fms_finance_*、fms_currency、fms_subject*、fms_auxiliary_*、fms_assist_combination、fms_initial_balance、fms_voucher_word、fms_digest、fms_voucher_template* 15 账套、财务参数、指标、币别、科目、辅助核算、初始余额、凭证字、摘要和模板
          凭证管理 fms_voucher、fms_voucher_entry 2 凭证主表和凭证分录
          账簿管理 — 0 根据初始余额与凭证分录实时查询，不建独立账簿表
          报表管理 fms_report_template、fms_balance_sheet_*、fms_income_statement_*、fms_cash_flow_* 9 三大财务报表的配置、期间结果和现金流辅助数据
          结账管理 fms_closing* 4 结账方案、结账模板、结转凭证和会计期间状态

          # 5.1 设置管理

          账套是 FMS 的核算主体，一个后台账号可以加入多个账套。账套初始化时确定本位币、启用期间、会计制度、科目级次和账簿余额方向；首页指标配置决定首页展示哪些指标及其取数公式。

          核算基础按「币别 → 辅助核算 → 会计科目 → 财务初始余额」组织：币别提供本位币和外币资料，科目绑定辅助核算、外币和数量核算，初始余额保存启用期间的科目余额和辅助明细。

          凭证字决定凭证编号和打印标题，常用摘要用于快速填写分录摘要，凭证模板用于保存和套用常见借贷分录。它们不参与建账，只服务于「录凭证」页面。

          • 《【设置】账套管理、财务参数、财务指标》
          • 《【设置】币别、科目、辅助核算、初始余额》
          • 《【设置】凭证字、常用摘要、凭证模板》

          # 5.2 凭证管理

          围绕「录凭证 → 查凭证 → 审核 → 凭证汇总」形成日常账务闭环，并提供附件、导入、打印、移动和整理能力。

          • 《【凭证】凭证管理》

          # 5.3 账簿管理

          明细账、总账、科目余额表、多栏账、核算项目账和数量金额账，均根据初始余额与凭证分录实时查询，不建立独立账簿表。

          • 《【账簿】账簿管理》

          # 5.4 报表管理

          资产负债表、利润表和现金流量表按期间生成，支持公式修改、勾稽检查、导出和打印；现金流量表另外提供辅助数据调整。

          • 《【报表】财务报表》

          # 5.5 结账管理

          结账前检查待审核凭证、初始余额、凭证号、损益结转和财务报表；检查通过后关闭当前期间，发现错误时按会计期间倒序反结账。

          • 《【结账】期末结账》
