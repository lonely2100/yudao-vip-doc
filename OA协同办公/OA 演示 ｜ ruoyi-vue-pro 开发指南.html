          OA 演示

          # 1. 演示地址

          OA（Office Automation，办公自动化）用于企业日常协作和行政办公，提供日程、任务、计划、汇报、公告、讨论、通讯录、笔记、企业邮箱、企业云盘、公文和各类办公申请。

          # 1.1 OA 管理后台

          • 演示地址：http://dashboard-vue3.yudao.iocoder.cn/ (opens new window)
          • 菜单："OA 办公协同"下的「工作台」「考勤管理」「公告管理」「任务管理」「日程管理」「工作计划」等菜单
          • 仓库：https://github.com/yudaocode/yudao-ui-admin-vue3 (opens new window) 的 oa 目录，基于 Vue3 + Element Plus 实现

          工作台展示今日考勤、通讯录、讨论区、待办任务、公告通知、工作计划和行事历。点击卡片或【更多】，可以进入对应业务页面。

          工作台对应 @/views/oa/home/index.vue，各区块分别调用考勤、通讯录、讨论、任务、公告、计划和日程接口。

          # 1.2 OA 后端

          支持 Spring Boot 单体、Spring Cloud 微服务架构

          • 单体仓库：https://github.com/YunaiV/ruoyi-vue-pro (opens new window) 的 yudao-module-oa 模块
          • 微服务仓库：https://github.com/YunaiV/yudao-cloud (opens new window) 的 yudao-module-oa 服务

          后台用户、部门和权限复用 System 模块，文件上传复用 Infra 模块，办公申请的审批复用 BPM 模块。

          # 1.3 OA 移动端

          OA 提供 uni-app 移动端，协作、办公、行政和流程申请均已迁到手机端，详见 《移动端 OA》。

          • 仓库：https://github.com/yudaocode/yudao-ui-admin-uniapp (opens new window) 的 pages-oa 目录

          # 2. OA 启动

          参见 《OA 手册 —— 功能开启》 文档。

          专属交流社区，欢迎扫码加入。

          # 4. 功能描述

          主要分为日常协作、办公服务、行政管理和流程申请四类，工作台汇总本人需要处理的信息。

          • 日常协作：日程、任务、工作计划、工作汇报、公告、讨论、通讯录和笔记。
          • 办公服务：企业邮箱、企业云盘。
          • 行政管理：办公用品、用印、会议室和车辆。
          • 流程申请：公文、出差、费用报销、请假、加班、转正和离职。

          办公申请通常先保存草稿，再从列表提交审批。审批通过后的业务操作随场景不同：用品需要实际发放，会议室需要开始和完成使用，车辆还需要提交还车申请。

          # 5. 表结构

          OA 共 48 张表，表名统一以 oa_ 为前缀。

          模块 子前缀 表数量 核心职责
          工作协作 oa_schedule*、oa_task*、oa_plan、oa_work_report 7 日程、参与人、任务、反馈、计划和汇报
          信息协作 oa_announcement*、oa_discussion*、oa_vote*、oa_contact*、oa_note* 13 公告接收、讨论投票、联系人和笔记共享
          企业邮箱 oa_mail_* 4 服务、个人账号、文件夹和邮件
          企业云盘 oa_file_* 3 文件节点、共享权限和收藏
          办公用品与用印 oa_supply_*、oa_seal* 5 用品、申请明细、发放归还、印章和用印申请
          会议室与车辆 oa_meeting_room*、oa_vehicle* 5 资源资料、会议室预定、用车和还车
          公文管理 oa_official_doc_* 3 套红模板、发文和收文
          出差与报销 oa_travel_*、oa_reimbursement 3 出差申请、差旅报销和普通费用报销
          考勤与人事申请 oa_attendance、oa_leave_apply、oa_overtime_apply、oa_regular_apply、oa_resign_apply 5 打卡、考勤统计和四类人事申请

          # 5.1 日常协作

          日程按创建人和参与人共享；任务记录各接收人的进度和反馈；计划提供管理范围内的报表与点评；工作汇报按日报、周报、月报统计填写情况。

          公告保存接收人的阅读状态，讨论区支持回复、点赞和投票。联系人和笔记通过共享关系开放给其他用户。

          • 《【协作】日程、任务、计划与汇报》
          • 《【协作】公告、讨论、通讯录与笔记》

          # 5.2 办公服务

          企业邮箱对接 IMAP、SMTP 服务，用户绑定个人账号后收发邮件；企业云盘通过文件目录和用户、部门授权维护共享范围。

          • 《【办公】企业邮箱》
          • 《【办公】企业云盘》

          # 5.3 行政管理

          办公用品在发放时扣库存、归还时补库存；用印申请关联印章资料。会议室预定检查时间和成员范围，用车与还车通过两张申请单关联。

          • 《【行政】办公用品、用印管理》
          • 《【行政】会议室、车辆管理》

          # 5.4 流程申请

          公文按套红模板、发文和收文组织。差旅报销可关联已通过的出差申请，普通费用报销单独保存费用明细。请假、加班、转正和离职申请分别记录业务资料，审批使用 BPM 流程。

          • 《【流程】公文管理》
          • 《【流程】出差、费用报销》
          • 《【流程】考勤、请假、加班、转正与离职》
