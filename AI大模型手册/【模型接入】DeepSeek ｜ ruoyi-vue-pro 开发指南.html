          【模型接入】DeepSeek

          项目基于 Spring AI 提供的 spring-ai-deepseek (opens new window)，实现 DeepSeek 的接入：

          功能 模型 Spring AI 客户端
          AI 对话 deepseek-flash、deepseek-v4-pro DeepSeekChatModel
          AI 绘画 Janus-Pro 暂不支持

          # 1. 申请密钥

          DeepSeek 目前有 3 种方式，可以进行使用：

          ① 方式一：官方 API：DeepSeek 提供官方 API 服务，并且价格非常便宜，一般建议直接采用这种方式使用。

          ② 方式二：私有化部署：DeepSeek (opens new window) 有开源模型，所以可以本地私有化部署使用。

          ③ 方式三：云厂商部署：类似阿里云、字节、腾讯等厂商，私有化部署了 DeepSeek，然后提供 API 服务。

          # 1.1 方式一：官方 API 申请

          ① 在 DeepSeek 开放平台 (opens new window) 上，注册一个账号。目前，默认注册就送 500w tokens，还是蛮爽的。

          ② 在 API keys (opens new window) 菜单，创建一个 API key 即可。

          申请完成后，可以在我们系统的 [AI 大模型 -> 控制台 -> API 密钥] 菜单，进行密钥的配置。只需要填写“密钥”，不需要填写“自定义 API URL”（因为 Spring AI 默认官方地址）。如下图所示：

          # 1.2 方式二：私有化部署

          友情提示：

          由于 DeepSeek V4 模型尺寸比较大，Ollama 暂未提供本地部署的官方方案。当然，感兴趣也可以试试社区模型 deepseek-v4-flash (opens new window)。

          所以下面仍然使用 deepseek-r1 作为本地私有化部署示例。

          ① 访问 https://ollama.ai/download (opens new window)，下载对应系统 Ollama 客户端，然后安装。

          ② 安装完成后，在命令中执行 ollama run deepseek-r1 命令，一键部署 deepseek-r1 开源模型 (opens new window)，默认跑的是 deepseek-r1:7b 模型。

          # 2. 模型配置

          友情提示：

          目前 ai_model 表中，已经预置了一些模型，可以直接使用！！！

          # 2.1 AI 对话

          使用 《AI 对话》 时，需要在 [AI 大模型 -> 控制台 -> 模型配置] 菜单，配置对应的聊天模型。

          模型有：deepseek-flash、deepseek-v4-pro，可通过 《DeepSeek API 文档》 (opens new window) 查看。

          不同模型的最大输出 Tokens 不同，填写模型配置的 maxTokens 时可以参考下表：

          模型标识 最大输出 Tokens
          deepseek-flash 393216
          deepseek-v4-pro 393216

          以上数值来自官方 Lists Models (opens new window) 接口的 max_output_tokens。

          deepseek-flash 官方支持图片输入（input_modalities 含 image），deepseek-v4-pro 仅支持文本。在 [AI 大模型 -> 控制台 -> 模型配置] 中给模型勾选「图片」输入能力后，AI 对话会把图片作为多模态参数（UserMessage 的 Media）传递；但该平台复用 Spring AI 的 DeepSeekChatModel，实测它在 Spring AI 1.1.8 / 2.0.0 / 2.0.1 中仍会丢弃图片，是否支持以项目实际采用的 Spring AI 版本为准。未勾选时，图片仍按原附件逻辑以 Base64 文本拼接，只修改模型标识不能实现图片理解。详见 图片理解 (opens new window) 文档。

          # 3. 如何使用？

          ① 如果你的项目里需要直接通过 @Resource 注入 DeepSeekChatModel 等对象，需要把 application.yaml 配置文件里的 spring.ai.deepseek 配置项，替换成你的！

          spring:
  ai:
    deepseek: # DeepSeek
      api-key: ${DEEPSEEK_API_KEY}
      chat:
        options:
          model: deepseek-flash

          ② 如果你希望使用 [AI 大模型 -> 控制台 -> API 密钥] 菜单的密钥配置，则可以通过 AiModelService 的 #getChatModel(...) 方法，获取对应的模型对象。

          ① 和 ② 这两者的后续使用，就是标准的 Spring AI 客户端的使用，调用对应的方法即可。

          另外，DeepSeekChatModelTests 里有对应的测试用例，可以参考。

          # 4. 云厂商部署

          除了 DeepSeek 官方 API，也可以通过云厂商部署的 DeepSeek 模型接入。不同厂商的 API URL、模型标识、thinking 返回格式可能不同，建议优先按厂商文档填写“自定义 API URL”和模型标识。

          # 4.1 阿里云 API

          ① 参考 《【模型接入】通义千问》 文档，申请阿里云密钥，并配置 API 密钥。

          ② 配置聊天模型时，字段可以按下面填写：

          • 所属平台：TongYi
          • 模型标识：deepseek-v4-pro 或 deepseek-v4-flash
          • API 密钥：选择前面配置的阿里云密钥

          具体模型可见阿里云百炼的 deepseek-v4-pro (opens new window) 和 deepseek-v4-flash (opens new window)。

          # 4.2 腾讯云 API

          ① 如果使用腾讯云 TokenHub，可以参考 《【模型接入】腾讯混元》 文档，申请腾讯 API Key，并配置 API 密钥。

          ② 配置聊天模型时，字段可以按下面填写：

          • 所属平台：HunYuan
          • 模型标识：deepseek-v4-flash 或 deepseek-v4-pro
          • API 密钥：选择前面配置的腾讯混元密钥

          具体模型可见腾讯云 TokenHub 的 deepseek-v4-flash (opens new window) 和 deepseek-v4-pro (opens new window)。

          # 4.3 字节火山云 API

          ① 参考 《【模型接入】字节豆包》 文档，申请字节密钥，并配置 API 密钥。

          ② 配置聊天模型时，字段可以按下面填写：

          • 所属平台：DouBao
          • 模型标识：deepseek-v4-pro-260425 或 deepseek-v4-flash-260425
          • API 密钥：选择前面配置的字节豆包密钥

          具体模型可见火山方舟的 deepseek-v4-pro (opens new window) 和 deepseek-v4-flash (opens new window)。

          # 4.4 百度 API

          ① 参考 《【模型接入】文心一言》 文档，申请百度千帆密钥，并配置 API 密钥。

          ② 配置聊天模型时，字段可以按下面填写：

          • 所属平台：YiYan
          • 模型标识：deepseek-v4-pro 或 deepseek-v4-flash
          • API 密钥：选择前面配置的百度千帆密钥

          具体模型可见百度千帆的 DeepSeek-V4-Pro (opens new window) 和 DeepSeek-V4-Flash (opens new window)。

          # 4.5 硅基流动 API

          ① 参考 《【模型接入】硅基流动》 文档，申请硅基密钥，并配置 API 密钥。

          ② 配置聊天模型时，字段可以按下面填写：

          • 所属平台：SiliconFlow
          • 模型标识：deepseek-ai/DeepSeek-V4-Pro 或 deepseek-ai/DeepSeek-V4.1-Flash
          • API 密钥：选择前面配置的硅基流动密钥

          具体模型可见硅基流动的 DeepSeek-V4-Pro (opens new window) 和 DeepSeek-V4.1-Flash (opens new window)。
