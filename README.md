# 芋道源码 VIP 文档（离线版 8.0）

芋道源码（ruoyi-vue-pro）VIP 文档整站的离线存档，共 **382 篇正文 + 1 个入口页**，全部是自包含的 HTML，**不联网也能正常浏览**。

## 快速开始

**方式一：直接打开**

双击根目录的 `index.html`，用 Chrome / Edge 打开即可，从首页点进任意手册与文章。

**方式二：起本地服务（推荐）**

```bash
# 在仓库根目录执行
python -m http.server 8000
# 浏览器访问 http://localhost:8000
```

用本地服务的好处是：文章内的相对链接、`common/` 下的导航脚本（左目录树、右侧标题目录）加载行为与线上一致，不会遇到 `file://` 下的个别限制。
